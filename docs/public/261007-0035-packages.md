# Packages and compatibility

Troolio targets .NET 10 and Microsoft Orleans 10. The framework and optional samples-repository extensions have separate version lines.

## Framework packages

Keep these framework packages together at **10.0.8** when installing more than one:

| Package | Use |
| --- | --- |
| [Troolio.Core](https://www.nuget.org/packages/Troolio.Core/10.0.8) | Actor, command, event, state, store, orchestration and projection contracts |
| [Troolio.Agents](https://www.nuget.org/packages/Troolio.Agents/10.0.8) | Agent definition and run actors |
| [Troolio.SqlServer](https://www.nuget.org/packages/Troolio.SqlServer/10.0.8) | SQL Server selected-route, transaction, projection and effect adapters |
| [Troolio.KurrentDB](https://www.nuget.org/packages/Troolio.KurrentDB/10.0.8) | KurrentDB selected-route, queue and recovery adapters |
| [Troolio.KurrentDB.SqlServer](https://www.nuget.org/packages/Troolio.KurrentDB.SqlServer/10.0.8) | SQL coordination for KurrentDB broker, journal, admission and projections |

```sh
dotnet add package Troolio.Core --version 10.0.8
```

Install only what your application needs. A package reference resolves dependencies; the host must still select its route and configure compatible services.

## Optional extensions

These packages are **10.0.2** and depend on public Core **10.0.8**:

| Package | Use | Guide |
| --- | --- | --- |
| [Troolio.Projection.EntityFramework](https://www.nuget.org/packages/Troolio.Projection.EntityFramework/10.0.2) | EF Core 10 relational read-model writes | [EF projections](ef-projections.html) |
| [Troolio.Projection.Redis](https://www.nuget.org/packages/Troolio.Projection.Redis/10.0.2) | Redis hashes, partitions and bounded change-feed queries | [Redis projections](redis-projections.html) |
| [Troolio.Stores.EventStore](https://www.nuget.org/packages/Troolio.Stores.EventStore/10.0.2) | Ordinary `IStore` persistence using modern KurrentDB/EventStore gRPC | [Ordinary gRPC storage](eventstore-store.html) |
| [Troolio.Stores.Marten](https://www.nuget.org/packages/Troolio.Stores.Marten/10.0.2) | Ordinary `IStore` persistence through PostgreSQL and Marten | [Marten storage](marten-store.html) |

```sh
# Add an EF projection and, optionally, durable ordinary event storage.
dotnet add package Troolio.Projection.EntityFramework --version 10.0.2
dotnet add package Troolio.Stores.EventStore --version 10.0.2
```

The EventStore and Marten extensions implement ordinary actor storage. They are not substitutes for the framework's selected atomic-route contracts. EF and Redis are read-side integrations; selecting either does not establish a durable event-to-projection outbox or a global transaction. Configure those contracts explicitly when the application requires them.

## Message serialization

Assemblies declaring actor interfaces, messages, states or transport models reference the Orleans SDK explicitly:

```xml
<PackageReference Include="Troolio.Core" Version="10.0.8" />
<PackageReference Include="Microsoft.Orleans.Sdk" Version="10.0.0" PrivateAssets="all" />
```

```csharp
[GenerateSerializer]
public record AddItem(Metadata Headers,
    [property: Id(0)] Guid ItemId,
    [property: Id(1)] string Description) : Command<IShoppingListActor>(Headers);
```

Keep member IDs stable as a message evolves. Check provider compatibility separately from the framework version; see [hosting](host-setup.html), [serialization](stores-and-serialization.html) and each extension guide.
